1. ОБЗОР ПРОЕКТА
------------------------------------------------------------------------------
Advanced Site Analyzer — десктопный инструмент (Python 3.11+ / PyQt5) для
комплексной разведки и анализа веб-сайтов. Программа объединяет в едином
интерфейсе пассивную разведку (recon), перечисление субдоменов, перехват и
анализ динамического трафика (API-эндпоинты, токены), обход paywall, захват
и оффлайн-клонирование фронтенда, извлечение изображений/видео и анализ
дизайн-системы (палитра, типографика).

Сценарии запуска:
  • GUI       — main.py (основной режим, PyQt5, 13 вкладок).
  • CLI       — main_orchestrator.py (единый pipeline из 6 фаз).
  • Web/LAN   — remote/web_app.py (консоль управления на FastAPI, порт 5000).

Целевая поставка: автономный .exe через PyInstaller (build.spec). Тяжёлые
зависимости (Playwright, yt-dlp, FastAPI) опциональны и не бандлятся в .exe.

2. ЧТО УЖЕ РЕАЛИЗОВАНО
------------------------------------------------------------------------------
Ядро (core/):
  • recon_engine.py        — IP-резолв + гео (ip-api), фингерпринт CMS/стека,
                             фавиконы, PWA-манифест.
  • subdomain_scanner.py   — пассивное перечисление (crt.sh, HackerTarget) +
                             brute-force словарём.
  • dynamic_analyzer.py    — перехват XHR/Fetch через Playwright, извлечение
                             API-эндпоинтов, JSON-структур, auth-заголовков.
  • paywall_bypass.py      — 3 стратегии: Googlebot-спуфинг, вырезание JS,
                             Wayback Machine.
  • content_capture.py     — обход и сохранение HTML-страниц сайта.
  • frontend_cloner.py     — скачивание CSS/JS/шрифтов/картинок + переписывание
                             ссылок в относительные (оффлайн-копия).
  • design_analyzer.py     — извлечение палитры цветов и типографики -> JSON.
  • api_key_extractor.py   — поиск API-ключей/секретов в коде страниц.
  • vuln_scanner.py        — эвристические уязвимости по recon+dynamic.
  • api_dumper.py          — дамп перехваченных API-ответов на диск.
  • image_extractor.py / video_downloader.py — извлечение медиа (yt-dlp).
  • anti_detect_engine.py  — сессия с ротацией UA, cookie, retry-backoff.
  • cloudflare_bypass.py   — обход базовых проверок Cloudflare.

GUI (gui/main_window.py — каркас ~280 строк + per-tab модули gui/tab_*.py):
  • 13 вкладок: Recon & Intel, Subdomain Scanner, API Key Scanner, Site
    Capture, Clone Frontend, Video Downloader, Image Extractor, Design Lab,
    Cookie Security Audit, Final Report & Collection, Dashboard,
    История операций, System.
  • Многопоточность через QThread/QObject-воркеры (Worker, SubdomainWorker,
    CloneWorker, CaptureWorker) — UI не блокируется во время сканов.
  • [НОВОЕ] Единый раннер задач _start_task() (паттерн Signals/Slots): вся
    работа с потоками вынесена из вкладок в один метод, потоки учитываются в
    едином реестре self._tasks, teardown через deleteLater после реального
    завершения OS-потока. Поддержан одновременный запуск нескольких задач без
    гонок и краша «QThread destroyed while running» (проверено стресс-тестом
    на 5 параллельных задачах).
  • Dashboard: дедуплицированная таблица эндпоинтов (EndpointIndex), фильтр
    по типам, drill-down по кликам, кнопка «Run Scan», экспорт.

Утилиты (utils/):
  • operation_registry.py / sqlite_store.py — учёт операций в SQLite
    (data/operations.db, registry.db).
  • endpoint_index.py / pattern_analyser.py — нормализация и дедуп эндпоинтов,
    канонические DEFAULT_PATTERNS (API/GraphQL).
  • site_extractor.py, data_viewer.py, exporter.py, task_manager.py,
    system_logger.py, image_processor.py, video_processor.py,
    file_compression.py.

CLI / прочее:
  • main_orchestrator.py — pipeline из 6 фаз с записью жизненного цикла в
    реестр операций, итоговый pipeline_summary.json.
  • remote/web_app.py — LAN-консоль (FastAPI); корректно «глушится» в стаб
    при отсутствии fastapi.
  • build.spec + requirements.txt — упаковка PyInstaller.

3. ТЕКУЩИЙ ФУНКЦИОНАЛ (как это работает сейчас)
------------------------------------------------------------------------------
  • Запуск из GUI: пользователь вводит URL/домен на нужной вкладке; задача
    уходит в фоновый QThread-воркер, прогресс и результаты стримятся в UI,
    запись об операции пишется в SQLite.
  • CLI-pipeline: Recon (всегда) -> Paywall (опц.) -> Capture (всегда) ->
    Dynamic (опц.) -> Vuln scan (опц.) -> API dump (опц.). Каждая фаза
    оборачивается run_phase() и логируется в OperationRegistry; результаты
    складываются в ~/SiteAnalyzer/<домен>_<timestamp>/.
  • Dynamic-анализ поднимает headless Chromium (Playwright), слушает сетевой
    трафик, агрегирует эндпоинты/JSON/токены, отдаёт отчёт dynamic_report.json.
  • Эндпоинты прогоняются через EndpointIndex (нормализация + дедуп) и
    отображаются на Dashboard с возможностью провалиться в исходные вхождения.
  • Clone Frontend через AntiDetectSession скачивает ассеты и переписывает
    ссылки -> самодостаточная оффлайн-копия.

------------------------------------------------------------------------------
  • Монолитный GUI: [ЗАКРЫТО] gui/main_window.py разбит на per-tab
    mixin-модули gui/tab_*.py; каркас ужат до ~320 строк.
  • Многопоточность: [ЗАКРЫТО] краш разрушения QThread и риск гонок устранены

  • Зависимость от внешних сервисов: recon/субдомены завязаны на ip-api.com,
    crt.sh, HackerTarget, archive.org — нет обработки rate-limit/недоступности.
  • Тесты: нет полноценного покрытия (только examples/test_cases.py и
    ручной run_live_test.py).
  • Документация: отсутствует корневой README; часть логики описана только в
    docstring'ах модулей.
  • Дублирование: ImageExtractor/VideoDownloader присутствуют и в core/, и в
    utils/ (utils.image_processor / utils.video_processor) — требует ревизии
    на предмет дубля кода.
  • Конфигурация путей к БД и каталогам разнесена между GUI и CLI — стоит
    централизовать.
